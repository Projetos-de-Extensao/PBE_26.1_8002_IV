**Código da Disciplina:** IBM8936  

---

## Sobre o Projeto

Este projeto foi desenvolvido na disciplina de **Projeto Back-End**, com foco na aplicação prática de conceitos de desenvolvimento de sistemas utilizando arquitetura back-end moderna.

A proposta envolve a construção de uma solução robusta, escalável e organizada, aplicando boas práticas de programação, modelagem de dados e versionamento de código.

Durante o desenvolvimento, são trabalhados conceitos essenciais como:

- Programação Orientada a Objetos (POO)
- Estruturação de APIs e lógica de negócio
- Modelagem e manipulação de banco de dados
- Versionamento com Git e GitHub
- Organização de projetos em equipe
- Boas práticas de desenvolvimento com Django

---
